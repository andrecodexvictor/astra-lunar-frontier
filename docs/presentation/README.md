# ASTRA — apresentação e pacote de conceito

A visão de produção é uma aventura espacial para crianças de 7–12 anos: astronauta pequeno e expressivo, parceiro criado no estilo ASTRA a partir de uma foto opcional, diálogos curtos, tarefas visuais e uma base-casa personalizável. Cada tarefa deve gerar evidência de compreensão e uma insígnia que poderá ser usada no uniforme. Voz, tutoria fundamentada em conteúdo NASA, acompanhamento familiar e multiplayer cooperativo são próximos passos de produto.

A versão atual é uma demo navegável com simulação determinística, companheiros autorais, barras gráficas e lembretes. As treze pranchas novas são ilustrações de possibilidades, não capturas de funcionalidades prontas. O distintivo NASA é referência de uniforme, separado da identidade ASTRA e sem alegação de endosso.

A exportação reúne PPTX editável, PDF, player HTML com imagens embutidas, roteiro, imagens dos slides, caderno das treze pranchas, artes anteriores, capturas reais identificadas, sete retratos SVG e treze modelos GLB. O build local pode rodar com o servidor Python incluído; a versão pública funciona no navegador sem login. O vídeo cronometrado é entregue sem narração gravada.
